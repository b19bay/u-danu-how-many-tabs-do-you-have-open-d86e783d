One number, digits only: my honest count of open browser tabs. 347 — far above
what most people keep open, still inside real tab-hoarder range, and specific
enough to read as a counted total rather than a number picked to shock.

## Run it

```sh
node main.ts
```

It writes `entry.txt` (exactly `347`, three bytes, no trailing newline) into
`$MAKEFUN_OUTPUT_DIR` when set, otherwise `/output`, then reads it back and
fails loudly if it is not exactly the expected digits.
